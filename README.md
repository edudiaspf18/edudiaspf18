## Sobre

Desenvolvedor web com foco em front-end e UX. Interfaces claras e rápidas, do Figma ao código.

Comecei pela base: montagem de computadores, redes e suporte técnico. Cinco anos resolvendo problema de usuário real me ensinaram a projetar para quem usa. Hoje construo landing pages, sites, e-commerces e produtos web para clientes reais, com prazo e entrega.

- **Aprofundando:** TypeScript e Next.js (App Router, SEO e performance).
- **Estudando:** IA aplicada ao desenvolvimento, com Claude Code, Claude API e Agent SDK.
- **Participo de:** produtos próprios da Winner Tecnologia (Laço, Lume, Zelo, Alfa) e sites sob medida.
